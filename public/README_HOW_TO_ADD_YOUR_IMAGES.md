# Portfolio Image Directory Guide

Welcome! Here is where you can easily save all your personal profile photos and certificate images for your portfolio website.

## 📁 Directory Structure Overview

```text
public/
├── profile/
│   └── avatar.jpg                 <-- Save your profile picture here!
└── certificates/
    ├── cert-01-wns-cybersmart.jpg <-- Save WNS CyberSmart Certificate here!
    ├── cert-02-gfg-cpp.jpg        <-- Save GeeksforGeeks C++ Certificate here!
    ├── cert-03-iamneo.jpg         <-- Save iamNeo 150-Hour Certificate here!
    ├── cert-04-infosys-ml.jpg     <-- Save Infosys ML Certificate here!
    ├── cert-05-gfg-c.jpg          <-- Save GeeksforGeeks C Certificate here!
    └── cert-06-actopia.jpg        <-- Save Actopia Award Certificate here!
```

---

## 📸 Image Guide & Instructions

### 1. Profile Picture (`public/profile/`)
- Save your profile photo as: **`avatar.jpg`** inside `public/profile/`
- *Supported formats*: `.jpg`, `.png`, `.webp`, `.jpeg`

### 2. Certificates (`public/certificates/`)
- Save your certificate images inside `public/certificates/`:
  - `cert-01-wns-cybersmart.jpg`
  - `cert-02-gfg-cpp.jpg`
  - `cert-03-iamneo.jpg`
  - `cert-04-infosys-ml.jpg`
  - `cert-05-gfg-c.jpg`
  - `cert-06-actopia.jpg`

---

## 🚀 Why this works 100% on Vercel & Local:
- **Instant 0ms Loading**: No waiting for Google Drive servers to load.
- **100% Reliable**: Zero CORS errors, 403 Forbidden blocks, or login prompts.
- **Auto-Deploys**: When you upload your project to Vercel, Vercel automatically hosts all images in `public/` on global Edge servers.
